# Sistema de Votação Eletrônica Seguro

Repositório estruturado para a disciplina de Criptografia. 
Implementação do sistema de votação eletrônica seguro cobrindo as propriedades de sigilo, integridade, verificabilidade e auditabilidade.

## Como Executar a Fase 1 (No Ubuntu Linux)

1. Crie o ambiente virtual:
   ```bash
   python3 -m venv venv
   ```
2. Ative o ambiente virtual:
   ```bash
   source venv/bin/activate
   ```
3. Instale os pacotes necessários:
   ```bash
   pip install -r requirements.txt
   ```
